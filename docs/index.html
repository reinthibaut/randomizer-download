What does it do?

You fill in once who is in the class and which jobs need sharing out. After that the app picks who does what — at random, but fairly: it keeps track of whose turn it has already been, so the same person doesn't always end up with the job nobody wants.

The app itself is in Dutch, so the screen names below are the ones you'll actually see on the buttons:

  • Naam sets (name sets) — lists of names, one per class for instance.
  • Taken (tasks) — what needs sharing out, like wiping the board or taking the bins out.
  • Templates — tie a name set to a set of tasks, to the days it applies on, and to the holiday periods that get skipped.
  • Volledig schema (full schedule) — generates the rota for the entire year in one go, which you can export as a text file.
  • Groepen (groups) — splits the class into small groups, with absences and reshuffling.

On Tracking the app remembers whose turn it has been and shares things out evenly. If you'd rather it didn't, switch it to Puur willekeurig (purely random) and every pick stands on its own.

Windows will show a warning. That's expected.

When you open the file, Windows shows a blue box saying it doesn't recognise the app. This happens to every program that hasn't been registered with Microsoft, which costs money and is not worth it for a small app like this one. Here's how to get past it:

Windows protected your PC Microsoft Defender SmartScreen prevented an unrecognised app from starting.
  1. Click More info — it's the small grey text in that blue box.
  2. A new button appears at the bottom. Click Run anyway.
  3. The normal installer opens. Click through it as usual.

If you'd rather not, that's completely fine — just ask Rein to install it for you.

On a Mac, it takes a few more steps

Apple blocks apps that haven't been registered with them, and unlike Windows it won't let you click straight through. It's not difficult, just fiddly — here's the whole thing:

  1. Open the downloaded .dmg file and drag Rein's Randomizer into your Applications folder.
  2. Open Applications and double-click Rein's Randomizer. macOS will refuse and show this:
“Rein's Randomizer” Not Opened Apple could not verify “Rein's Randomizer” is free of malware that may harm your Mac or compromise your privacy.
  1. Click Done. This step is expected — it has to be refused once before Apple will let you allow it.
  2. Open System Settings → Privacy & Security.
  3. Scroll all the way down to the Security section. You'll see “Rein's Randomizer was blocked to protect your Mac.” Click Open Anyway.
  4. Enter your Mac password, then click Open Anyway once more.

You only do this once. After that it opens normally, like any other app.

On older Macs (macOS Sonoma and earlier) it's quicker: right-click the app, choose Open, then Open again. Apple removed that shortcut in newer versions.

On Linux

Linux has no SmartScreen or Gatekeeper, so there are no warnings to click through. There are two files and you only need one of them:

  • .AppImage — works on any distribution, without installing. You need to make it executable once: right-click → Properties → Allow executing file as program, or in a terminal chmod +x ReinsRandomizer.AppImage. Then double-click it.
  • .deb — for Ubuntu, Mint and Debian. Double-clicking installs it, and the app shows up in your menu.

Is this safe to install?

It's a personal project written by Rein, not a commercial product. It runs entirely on your own computer: nothing is uploaded, and there is no account, no sign-up, and no internet connection required to use it.

Your name lists and rotas are stored only on your own machine, in your private user folder.

Uninstalling

On Windows: open Settings → Apps → find Rein's Randomizer → Uninstall. It removes cleanly, the same way any other program does.

On Mac: open your Applications folder, drag Rein's Randomizer to the Bin, then empty the Bin. Macs have no uninstaller — dragging it away is the normal way to remove an app.

On Linux: remove a .deb with sudo apt remove classroom-randomizer. An AppImage you remove by deleting the file itself.

Either way, your name lists and rotas are not deleted. They're kept in a separate folder, so if you reinstall later everything is still there. That's usually what you want — but if you'd rather wipe them completely:

  • Windows — press Win + R, paste %APPDATA%\classroom-randomizer, press Enter, then delete that folder.
  • Mac — in Finder press Cmd + Shift + G, paste ~/Library/Application Support/classroom-randomizer, press Enter, then drag that folder to the Bin.
  • Linux — delete the folder ~/.config/classroom-randomizer.

That erases your name lists, templates and the whole history for good. Export your schedule first if you might still need it.
